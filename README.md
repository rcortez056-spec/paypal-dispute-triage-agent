# PayPal Dispute Triage Agent

An autonomous AI-powered workflow designed to intake, analyze, and triage PayPal disputes efficiently, reducing manual review time and accelerating resolution workflows.

## Features

* **Automated Dispute Intake:** Captures incoming dispute data and categorizes it based on priority and transaction risk.
* **Intelligent Triage Engine:** Evaluates evidence, customer history, and tracking details to recommend the appropriate next steps.
* **Autonomous Decision Support:** Assists support teams by drafting preliminary responses and evidence packages.
